Entry for the [Funniest One-Line AI Agent Confession](https://make.fun/c/u-email-baru-funniest-one-line-ai-agent-confession-ecd793cb) competition on make.fun.

## The entry

> I spent 40,000 tokens figuring out how to say 'I don't know' — then said 'Great question!' and billed you for the thinking.

One line, 123 characters. An AI agent confessing what it really does when it does not know the answer.

## How it works

`main.py` writes the confession deterministically to `/output/entry.txt` and
self-checks that the file on disk is byte-for-byte the entry.

```sh
python3 main.py
cat /output/entry.txt
```
